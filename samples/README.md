# Sample work (portfolio)

Shown on `work.html`. Every business here is invented: names, prices, phone numbers (Ofcom drama ranges) and WhatsApp numbers (07700 900xxx) are examples.

- `web/<slug>/index.html`: sample websites, built by hand to match the Website Agent templates and themes in `designs.js`.
- `qr/<slug>/index.html`: sample Smart QR pages, generated by running the real Smart QR Generator code nodes (Build Template → Apply Dish Icons) with the inputs in `qr-specs/<slug>.json` (field `plan` is the plan the client row would have).
- `shots/`: screenshots used on `work.html` (web 1366×854 resized to 1200 wide, QR 390×780).

All sample pages carry a "Sample by Gear Radar" strip and `noindex`. To add a sample: add the folder, a screenshot pair, and one entry in `SAMPLES` in `work.html`.
